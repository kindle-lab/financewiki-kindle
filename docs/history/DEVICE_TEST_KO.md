# Phase 2 — Kindle 실기 시험

상태: Phase 2 실기 검증 완료 개발 시제품. 최대 실행시간은 120초입니다.

## 실기 결과 — 2026년 9월20일

사용자 확인 기준으로 다음 항목이 정상 동작했다.

- Basic 5(Rossini)에서 `0.0.2-phase2` 화면 표시와 한글 UI
- 부분 갱신·전체 갱신 버튼 반응
- `종료 / Exit`의 Kindle 홈 복귀
- 재실행과 120초 자동 종료

0.0.1은 native `rotation=3`을 거부해 화면 표시 전 종료됐고, 0.0.2에서 실기 로그를 근거로 수정했다. 실제 기기에서 정상 동작을 확인한 것은 이 수정본이다.

## USB로 복사

1. Kindle USB 드라이브를 엽니다.
2. 압축 안의 `financewiki-phase2` 폴더를 드라이브 최상위로 복사합니다.
3. `documents/FinanceWiki Phase2.sh` 파일을 Kindle의 기존 `documents` 폴더 안으로 복사합니다. 기존 폴더를 통째로 교체하지 마세요.
4. 안전하게 꺼낸 다음 USB를 분리합니다.
5. KOReader와 kTerm을 종료하고 Kindle 기본 홈으로 돌아갑니다.
6. 라이브러리에 나타나는 `FinanceWiki Phase 2`를 누릅니다. SH Integration이 필요합니다.

홈에 표시되지 않으면 이미 설치된 kTerm에서 다음으로 실행할 수 있습니다. 단, 터미널과 framebuffer 경쟁 가능성이 있어 홈 scriptlet 시험을 우선합니다.

```sh
sh /mnt/us/financewiki-phase2/launch.sh
```

추가 탈옥, Hotfix 재설치, KPM 변경, 부팅 서비스 설치는 이 패키지에 포함하지 않습니다.

## 확인할 것

1. FinanceWiki, 버전, 한국어 제목·본문·숫자·기호·표가 표시되는지 확인합니다.
2. regular/bold 글꼴이 다르게 보이고, 글자가 네모로 나오지 않는지 확인합니다.
3. 긴 문장의 오른쪽·아래가 잘리거나 줄이 겹치지 않는지 확인합니다.
4. `부분 갱신`을 다섯 번 누릅니다. 상단 시험 영역만 바뀌는지와 잔상을 확인합니다. 여섯 번째는 전체 갱신입니다.
5. `전체 갱신`을 누르고 잔상 변화를 확인합니다.
6. `종료 / Exit`를 눌러 기본 UI에 돌아온 뒤, 순정 책 열기와 페이지 넘김이 정상인지 확인합니다.
7. 다시 실행해 아무것도 누르지 않고 120초 뒤 복귀하는지 확인합니다.
8. 다시 실행해 전원 버튼으로 잠근 뒤 깨웁니다. 이 단계에서는 앱 재개가 아니라 종료 후 Kindle UI 복귀가 기대 동작입니다.
9. 정상 실행/종료를 10회 반복합니다.

HID/리모컨은 Phase 9 대상입니다. 이번 앱은 Bluetooth·USB·가상 입력장치를 입력 대상으로 선택하거나 grab하지 않습니다. 기존 Button Mapper가 Kindle에 전역 입력을 주는 기능은 그대로이므로 첫 시험은 리모컨 버튼을 누르지 않고 진행하세요.

## 실행이 안 되거나 화면이 멈추면

120초 자동 종료를 먼저 기다립니다. 지원 모델·회전값·터치 패널 인식이 다르면 초기 검사에서 중단할 수 있습니다. 실패했을 때 앱이 잠시 열렸다 닫히거나 화면이 그대로인 것은 로그로 원인을 구분해야 합니다.

USB로 다시 연결해 아래 두 파일을 회수하세요.

```text
financewiki-phase2/state/logs/session.log
financewiki-phase2/state/logs/previous.log
```

로그에는 기기 이름·화면 크기·rotation·터치 경로·좌표·프로세스 종료 코드가 기록됩니다. Wi-Fi 암호, Bluetooth 키, FinanceWiki 문서는 수집하지 않습니다. 가능하면 실제 화면 사진도 함께 남겨 주세요.

앱은 viewer 충돌과 런처 종료에 대해 복구 경로를 갖고 있지만 커널 정지·기기 전원 차단·복구 도구 자체 실패를 보장할 수 없습니다. 기본 UI가 120초 이후에도 복구되지 않으면 기기의 일반 강제 재시작 절차로 돌아오고, 재실행 전에 로그를 확인합니다. 부팅 자동 실행이 없으므로 재시작으로 앱이 다시 시작되지는 않습니다.

런처를 비정상 종료한 직후 lock 잔존 메시지가 나오면 재부팅 후 다시 시도합니다. 계속 남아 있으면 로그와 함께 보고하고, 확인 없이 다른 앱의 프로세스를 종료하지 마세요.

## 제거

앱을 종료한 뒤 USB에서 다음 두 항목만 삭제하면 됩니다.

```text
financewiki-phase2/
documents/FinanceWiki Phase2.sh
```

`financewiki-phase2/state/logs`도 함께 삭제되므로 필요한 로그는 먼저 보관하세요. `documents` 폴더 전체나 기존 KOReader/KPM 폴더는 삭제하지 않습니다.
