# FinanceWiki Kindle 1.1.0

기준일: 2026년 10월 24일

1.0.0 후보(코덱스 작업, 로컬 커밋 `b3a3c5e`)를 실기기에서 검토하고 고친 첫 배포판입니다. 1.0.0은 킨들에서 한 번도 문서를 띄우지 못했습니다.

## 1.0.0에서 막혔던 것

| 문제 | 증상 | 1.1.0 |
|---|---|---|
| KPM 패키지 형식 | `manifest.json`이 압축 안쪽 폴더에 있고 v2 형식이 아니라 KPM이 설치를 거부 | 최상위 v2 매니페스트, id `fw` |
| 실행 순서 | 동기화 전에 캐시 점검을 해서 빈 캐시로 종료 | 동기화 → 점검 |
| 목록 해석 | `"key": "value"`처럼 콜론 뒤 공백을 못 읽어 모든 문서 거부 | 공백 허용, 실제 645개 문서로 검증 |
| 전부 아니면 전무 동기화 | 645개 중 하나만 실패해도 받은 문서를 모두 버림 | 문서마다 저장, 다음 실행에서 이어 받기 |
| 120초 강제 종료 | 시험판 안전장치가 남아 2분마다 종료 | 제거. 15분 무입력 또는 전원 버튼으로 종료 |
| 서재 항목 사라짐 | 첫 실행에 서재 실행 파일을 같은 내용으로 덮어써서 킨들 서재가 항목을 지움 | 내용이 다를 때만 복사 |
| 홈 화면 밀림 | 종료 후 상태 표시줄이 사라지고 홈이 한 줄 내려감 | 종료 때 홈 다시 그리기 (0.7.0 방식) |

## 화면 표시

| 문제 | 1.1.0 |
|---|---|
| 문서 머리말(YAML)이 본문 맨 위에 그대로 표시 | 숨김 |
| `*`, `_`, `` ` ``를 무조건 지워 `last_verified` → `lastverified` | 짝이 맞는 강조만 제거, 단어 안 `_` 유지 |
| 560바이트마다 잘라 문장 중간 `…`, 목록 많은 쪽은 넘쳐서 종료 | FBInk로 재서 화면에 맞게 나눔 |
| 하위 목록이 평평하게, 표는 `\|---\|` 그대로 | 들여쓰기, 표는 "열 이름: 값" |
| 제목이 본문과 같은 크기 | 고딕 굵게, 단계별 크기 |
| 서체가 가늘어 흐림 | 0.7.0과 같은 Noto CJK KR을 굵기 고정(명조 600, 고딕 500) |
| 페이지마다 화면 번쩍임 | 6번에 한 번만 |
| 경로순 넘기기만 가능 | 위키 첫 화면에서 시작, 링크 줄 탭으로 이동, 뒤로 |
| 쪽수 모름, 끝에서 다음 문서로 넘어감 | `3 / 12` 표시, 문서 안에서만 이동 |
| 동기화 중 화면 변화 없음 | 진행 화면(단계, 개수, 막대, 문서 제목) |

## 배포

- `/var/local/kmc/bin/kpm -y install fw` 한 줄로 설치
- 서재의 **FinanceWiki 업데이트**로 이후 업데이트
- 설정은 데이터 폴더에 저장되어 업데이트 뒤에도 유지

## 실기기에서 확인한 것

Kindle Basic 11세대(KT6, 펌웨어 5.19)에서 MTP로 직접 설치해 확인했습니다.

- 처음 전체 받기(문서 645개, 20개 단위로 저장)
- 첫 화면과 인덱스 문서에서 링크 줄 탭으로 이동
- 글자 크기·서체 바꾸기, 종료 후 홈 복귀
- 문서 쪽수 계산: 문서당 1~36ms

KPM 허브를 통한 설치(`kpm -y install fw`)와 **FinanceWiki 업데이트**는 허브 등록 뒤에 실기기에서 확인해야 합니다.
